## Design Context

### Product
Serene1004 is a personal frontend developer portfolio presented as a simple retro desktop workspace. Visitors browse project folders, open a project window for its details, and find profile and contact information together in the AboutMe folder.

### Users
Hiring managers, frontend developers, and potential collaborators. Help them find relevant work quickly, understand the developer's role and implementation decisions, and find profile and contact information without learning a complex interface.

### Brand Personality
Calm, organized, and personal: a tidy workstation with a distinct retro-computing character. The interface should feel deliberate and approachable, with the information always easy to scan.

### Visual Direction
- Keep the Windows-like desktop metaphor: a full-width header, a desktop area with shortcuts and project folders, movable project windows on desktop, and a persistent taskbar.
- Use pixel art for desktop icons, project folders, and window chrome. Keep all interface text in a highly legible non-pixel font.
- Keep the desktop background plain and quiet. Avoid decorative scenery, 3D effects, broad transparency, blur, glow, and unrelated visual effects.
- Present the AboutMe profile folder first, followed by work projects and then personal side projects. Do not add visible category headings to the desktop rows.
- Use the supplied AboutMe pixel icon for the profile folder, supplied pixel icons for work projects, and authentic project-specific images for side projects. Use the owner's logo as a temporary placeholder only when an icon is missing.
- Prefer opaque surfaces, crisp edges, restrained borders, and clear spacing. Use square geometry for desktop windows and folder tiles; the owner's logo is circular.
- Keep spacing on the 2px/4px token scale and define typography sizes in `assets/css/tokens.css`; use global styles for resets and shared behavior, and component files for desktop, taskbar, and window UI.
- The taskbar places open folder windows after Start and keeps language, weather, and calendar controls grouped at the right, in that order.
- On mobile, retain the desktop identity while making shortcuts and project details comfortable to tap and read. Project windows should fit the viewport and support straightforward dismissal.

### Color Palette
- Paper background: `#F3F0E7`
- Raised paper surface: `#FBFAF6`
- Ink text: `#252B29`
- Secondary text: `#5E6863`
- Muted teal accent: `#39766F`
- Teal tint: `#DCE9E4`
- Subtle divider: `#D6D8D0`

Use teal for meaningful interactive states, links, and selection. Do not rely on color alone to communicate state; keep contrast and keyboard focus visible.

### Design Principles
1. Make project names, summaries, roles, and outcomes more prominent than decoration.
2. Keep the folder-to-information interaction central on the home desktop; show profile and contact information together in the AboutMe window.
3. Treat pixel art as a focused visual language for icons and desktop chrome, not as a text style or a reason to add background decoration.
4. Keep surfaces opaque and the palette restrained. Avoid ornamental effects that compete with project information.
5. Preserve clear keyboard operation, comfortable touch targets, responsive reading, and reduced-motion support.
